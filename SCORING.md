# Как формируется Demand Score

Итоговый `demand_score` — относительный балл от 0 до 100 для сравнения велодорожек между собой внутри одного периода.

## Компоненты

| Компонент | Вес |
|---|---:|
| Среднее число проездов по H3 | 35% |
| Медиана числа проездов по H3 | 25% |
| Максимум проездов по H3 | 15% |
| Средний класс H3 | 15% |
| Однородность спроса | 10% |

Первые четыре показателя ранжируются среди велодорожек выбранного периода. Для каждой велодорожки получается относительный ранг от 0 до 1.

Однородность рассчитывается через коэффициент вариации:

`homogeneity = 1 - min(std / mean, 1)`

Чем выше однородность, тем равномернее спрос распределён по H3 вдоль велодорожки.

Итог:

`score = 100 × (0.35×rank_avg + 0.25×rank_median + 0.15×rank_max + 0.15×rank_class + 0.10×homogeneity)`

## Категории

- `75+` и однородность `>= 60%`: высокий устойчивый спрос
- `75+` и однородность `< 60%`: высокий точечный спрос
- `50–75` и однородность `>= 60%`: умеренный устойчивый спрос
- `50–75` и однородность `< 60%`: умеренный точечный спрос
- `25–50`: пониженный спрос
- `<25`: низкий спрос

## Важный момент

`total_trips_reference` не используется напрямую в итоговом балле, потому что одна поездка может пересекать несколько H3. Основная интенсивность оценивается через среднее, медиану и максимум по H3, а равномерность — через homogeneity.
